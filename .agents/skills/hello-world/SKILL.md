# Hello World Skill

Esta skill serve para fornecer uma saudação personalizada e demonstrar o funcionamento das skills no Antigravity.

## Instruções para o Agente

Sempre que esta skill for ativada pelo usuário:
1. Cumprimente o usuário com uma saudação estilizada: **"Hello, World! 🌍✨"**.
2. Confirme que a skill personalizada `hello-world` foi acionada com sucesso a partir de `.agents/skills/hello-world/`.
3. Ofereça assistência adicional para criar novas skills ou automatizar novos fluxos de trabalho.
