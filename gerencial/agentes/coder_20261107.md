# Evolução e Calibração de Conhecimento: Estagiário Codificador (`/coder`)

## 1. Contexto da Calibração
O agente herdado do repositório central (`modulo_agents`) estava estritamente calibrado para o ecossistema Django 5.x / Web / Aplicações Financeiras. Neste projeto, a realidade é um **Bot Conversacional Inteligente para Discord** baseado em arquitetura assíncrona orientada a eventos (`discord.py`, `asyncio`, ChromaDB, SQLite WAL, Function Calling e roteamento híbrido de LLMs).

A calibração foi conduzida pelo `/gerente` seguindo a **Rota 3 (Rito Formal de Entrevista)** em 4 dimensões essenciais, todas aprovadas pelo Arquiteto-Chefe.

---

## 2. Matriz Antes vs Depois

| Dimensão | Antes (Herdado do Central) | Depois (Calibrado para Discord Bot) |
| :--- | :--- | :--- |
| **Arquitetura de Módulos** | `services.py` e `selectors.py` desacoplados, models Django com `UniqueConstraint`. | **Padrão Nativo do Bot:** Novos comandos em `discord/commands/`, tools com schema em `discord/tools/*_tools.py` via `@register_tool`, lógica de negócio em managers dedicados (`*_manager.py`) e persistência via `database.py` e `vector_db.py`. |
| **Concorrência & Event Loop** | Transações síncronas (`transaction.atomic()`), sem restrição assíncrona. | **Zero Bloqueio:** I/O de disco e CPU pesada (PyMuPDF, faster-whisper, SQLite pesado) obrigatoriamente via `await asyncio.to_thread(...)`. Requisições HTTP em clientes assíncronos (`aiohttp`/`httpx`). Proibido `time.sleep()`. |
| **Estratégia de Testes** | `django.test.TestCase` com runner do Django. | **Testes Assíncronos & Mocks:** Testes automatizados com `unittest.IsolatedAsyncioTestCase` ou `pytest-asyncio` com mocks para eventos do Discord e LLM, acompanhados de scripts de bancada pré-commit. |
| **Datas & Contexto** | `django.utils.timezone.localdate()` obrigatório. | **ZoneInfo & ContextVars:** Uso estrito de `zoneinfo.ZoneInfo` ou helper `get_agora()`. Isolamento por requisição via `context_manager.py` (`ContextVars`). Retorno de tools padronizado: `{"sucesso": bool, "dados": Any, "erro": Optional[str]}`. |
